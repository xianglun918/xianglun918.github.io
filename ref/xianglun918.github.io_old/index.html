  • 实验室研究助理

    于学校机器人实验室 2016-2019

    完全凭兴趣参与的工作，通过简单的面试就可以成为本科生研究助理。期间接触了机器人相关各方各面的知识，虽然都不算太深入，但确实是宝贵的经验。 大二刚开始是参加了改造简单的无动力遥控帆船的小比赛，主要任务就是把原来遥控器控制舵机的帆船改为电脑控制，算是很入门级别的项目了，Arduino+无线模块就实现了。 但也是我第一个全程参与实现的项目，还是颇有成就感的，最后还凭借队友高超的帆船操控技术赢了对手哈哈哈。

    大三转到了AGV组，AGV组的项目是与香港那边实验室合作的，我们被一个博士生带着主要也就是打打下手，学习基础知识。期间学习了ros系统，顺带学习了linux系统的一些常用命令 和文件系统，当然，也经历无数次的重装系统和环境配置。期间，用Gmapping帮忙扫描了实验室二维图片，也尝试用图像拼接的方法重建了一段学校的路面的俯视图， 后来由于过于拼成的图片过于扭曲，而且速度很慢放弃了。

    大四，被另外一个博士生带着做了一些弱监督学习方面的研究。后来参与了当时实验室几个研究生和博士生一起在做的京东机器人挑战赛。负责帮忙整理数据库，调整yolo物体检测算法的参数。 帮忙测试验证linux上整体程序的稳定性。也算是为优胜奖有了一点小小的贡献吧，哈哈。

  • 学校课程项目

    各种课的结课项目 2015-2021

    Python - 编程基础入门，课程最后的项目是两个组一起，实现一个迷宫寻路的小游戏互相比拼，第一次接触到算法。虽然知道了A*这种寻路算法的存在，最后由于编程技能和时间问题 还是用bfs实现的寻路。

    C++ - 程序设计，最后的项目是自己决定的，我们小组计划是做一个联网的类大富翁小游戏，最后分别实现了游戏的主要运行界面和联机界面，没有完成融合。算是学习了C++的基本知识， 期间使用了一个别人设计好的引擎，让画面看着比较炫酷。时间很赶，最后完成度很粗糙。

    网络安全 - 课程实验量很大，不算是自己做的项目，教授作业里引导着学习了SQL注入、堆栈溢出攻击、中间人攻击和跨站点攻击等网络安全相关知识。

    微处理器设计实验 - 每人一块STM32开发板，最后的项目实现了一个款双人弹球小游戏。第一次嵌入式开发经验，大量的寄存器设置让人头晕目眩。

    数字图像处理 - 用Haar级联分类器和Canny边缘检测器实现了一个简单快速的人脸轮廓识别算法。

    数据库 - 用Django和mySQL实现了一个简单的公交车管理系统，第一次接触数据库和python网络框架库。
