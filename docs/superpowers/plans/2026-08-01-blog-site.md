# xianglun918.github.io 博客站点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Jekyll + Chirpy 主题在 `xianglun918.github.io` 搭建个人博客，支持 Markdown 发布、分类/标签、搜索、RSS、Giscus 评论 + 匿名留言、图片目录管理、媒体嵌入、背景音乐播放器、暗色模式。

**Architecture:** 基于 Chirpy 主题（`cotes2020/jekyll-theme-chirpy`）的标准 Jekyll 结构。内容以 Markdown 存于 `_posts/`，经 GitHub Actions 构建部署到 GitHub Pages。自定义组件放在 `_includes/`（媒体嵌入、音乐播放器、匿名留言）。站点元数据配置于 `_config.yml`。

**Tech Stack:** Jekyll（v4.x）、Chirpy v7.6.0、Ruby 3.1+、GitHub Pages + GitHub Actions、lunr.js（内置搜索）、jekyll-feed、Giscus。

**前置环境问题（Task 0 处理）：**
- 本机 Ruby 2.6.10 过旧，Chirpy v7 需要 Ruby ≥ 3.1。需升级或用 Docker 开发容器。
- Chirpy 官方推荐用 GitHub Actions 部署（依赖 `jekyll-archives` 等插件，不在 GitHub Pages 官方白名单）。

**部署方式修正说明：** 本计划将 spec 中的「不接 CI/CD」改为「GitHub Actions 部署」，这是 Chirpy 主题的官方推荐路径（见 https://chirpy.cotes.page/posts/getting-started/ ）。实现完成后同步更新 spec 文档。

## Task 6: 悬浮背景音乐播放器

**Files:**

- [ ] **Step 1: 创建音乐播放器组件**

Create `_includes/music-player.html`：

```html
{%- comment -%}
悬浮背景音乐播放器。播放列表来自 site.music_playlist（在 _config.yml 声明）。
自动播放被浏览器拦截时降级为待用户点击。
{%- endcomment -%}
{% if site.music_playlist.size > 0 %}
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/aplayer@1.10.1/dist/APlayer.min.css">
<script src="https://cdn.jsdelivr.net/npm/aplayer@1.10.1/dist/APlayer.min.js"></script>
<div id="music-player" style="position:fixed;bottom:20px;right:20px;z-index:9999;width:300px;"></div>
<script>
(function () {
  var songs = [
    {% for item in site.music_playlist %}
    { name: "{{ item.title }}", url: "{{ item.src }}" }{% unless forloop.last %},{% endunless %}
    {% endfor %}
  ].map(function (s) { return { name: s.name, artist: "{{ site.author }}", url: s.url, cover: "{{ site.avatar }}" }; });
  var ap = new APlayer({
    container: document.getElementById("music-player"),
    audio: songs,
    mini: true,
    autoplay: false,
    theme: "#6366f1",
    listFolded: true
  });
})();
</script>
{% endif %}
```

- [ ] **Step 1: 创建 GitHub Actions 部署工作流**

Create `.github/workflows/pages-deploy.yml`：

```yaml
name: Deploy site to Pages

on:
  push:
    branches: [master]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v5
      - name: Build with Jekyll
        uses: actions/jekyll-build-pages@v1
        with:
          source: ./
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
